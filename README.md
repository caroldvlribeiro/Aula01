# Aula 01 — Revisão de TecProg I

Repositório destinado à revisão dos principais conceitos estudados em **Técnicas de Programação I (TecProg I)**, servindo como preparação para a disciplina de **Técnicas de Programação II (TecProg II)**.

O projeto reúne exercícios e exemplos desenvolvidos em **Java**, retomando conceitos fundamentais de programação e lógica para reforçar a base necessária para os próximos conteúdos da disciplina.

## 🎯 Objetivo

O principal objetivo deste projeto é revisar os conhecimentos adquiridos durante o semestre anterior e retomar conceitos importantes antes do início de **TecProg II**.

A revisão busca reforçar:

* Lógica de programação;
* Estruturas básicas da linguagem Java;
* Variáveis e tipos de dados;
* Operadores;
* Estruturas condicionais;
* Estruturas de repetição;
* Métodos;
* Organização do código;
* Fundamentos da programação orientada a objetos.

## 🛠️ Tecnologias utilizadas

* **Java**
* **IntelliJ IDEA**
* **Git**
* **GitHub**

## 📚 Conteúdos revisados

Durante a revisão, são retomados conceitos fundamentais vistos em **TecProg I**, preparando a base para os conteúdos mais avançados de **TecProg II**.

### Programação em Java

* Métodos;
* Parâmetros;
* Retorno de valores;
* Organização em classes;
* Instanciação de objetos;
* Conceitos iniciais de orientação a objetos.

## 🚀 Como executar

### 1. Clonar o repositório

```bash
git clone https://github.com/caroldvlribeiro/Aula01.git
```

### 2. Abrir o projeto

Abra a pasta clonada no **IntelliJ IDEA**.

### 3. Executar

Localize a classe Java que deseja testar dentro de:

```text
src/br/edu/fatecpg/tecprogII/
```

Depois, execute o método `main()` da classe desejada.

## 🎓 Contexto acadêmico

Este projeto foi desenvolvido como parte dos estudos da disciplina de **Técnicas de Programação II**, com a finalidade de revisar os conteúdos apresentados anteriormente em **Técnicas de Programação I**.

A proposta é consolidar os fundamentos de programação antes de avançar para conceitos mais complexos durante o novo semestre.
